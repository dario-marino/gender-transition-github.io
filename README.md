# Youth Gender Dysphoria Atlas

Interactive maps and charts of gender dysphoria diagnoses among youth in Washington and Oregon,
2017–2023, from U.S. commercial and Medicaid insurance claims. Manhattan Institute.

Static site: no build step and no server code. Upload this folder as-is to a GitHub repository and
turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

```
index.html                      the page
css/style.css                   all styling; brand colours and fonts are tokens at the top (:root)
js/atlas.js                     map, rankings, charts, filters (D3 7.8.5 + TopoJSON 3.0.2 from cdnjs)
data/atlas_data.json            the numbers (public version: cells under 11 patients withheld)
data/zip3_wa_or.geojson         3-digit ZIP area shapes for WA and OR
downloads/GD_Youth_Atlas_Data.xlsx / .csv   the same numbers as a table, with a Read me sheet
```

The page also loads U.S. state outlines from `cdn.jsdelivr.net/npm/us-atlas@3.0.1` for the
background map. If that fails, the ZIP areas still draw.

Each view has its own link: the URL hash records the filters, e.g.
`index.html#WA/prev/F/12-17/cum/986` (state / measure / sex / age band / period / ZIP3).

To open it locally, serve the folder over http (fetching JSON does not work from `file://`):

```
python -m http.server 8000
```

The data and map files are generated by the scripts in `../build/` from the internal workpapers.
Do not upload the internal workpaper CSVs: they contain unsuppressed small cells.
